# Mercedes Fault Library

Offline Android workshop app for recording Mercedes-Benz fault repairs and finding proven fixes later.

## First version

- Searchable repair records
- Vehicle, engine, mileage, symptoms, tests, cause and repair fields
- Diagnostic-screen photographs retained inside the app
- Automatic on-device recognition of standard P/B/C/U fault codes
- Confirmed-repair marker
- Offline Room database

Open the folder in Android Studio, allow Gradle to sync, connect the test phone and press **Run**.
